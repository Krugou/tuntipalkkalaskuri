# Hourly Wage Calculator (tuntipalkkalaskuri)

A Svelte + Tailwind CSS app that converts a monthly salary into an hourly wage.
Enter your monthly salary, then either your weekly or monthly working hours.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Pushes to `main` build the site and deploy it to GitHub Pages through
`.github/workflows/deploy.yml`. In the repository settings, set
**Settings → Pages → Build and deployment → Source** to **GitHub Actions**.
