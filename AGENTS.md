# Agent instructions

- Before pushing, run `npm run check`, `npm run lint`, `npm run format:check`, `npm test`, `npm run test:e2e`, and `npm run build`.
- Commit changes and push them directly to the `main` branch. Do not create or push feature branches or open pull requests unless the user explicitly asks.
- Never force-push. If a direct push to `main` is rejected, report the issue rather than rewriting history.
